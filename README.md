# Alpha Terminal / METABOT

NFT alpha terminal + mobile-ready mint bot.

## Mint on mobile

1. Open **`metabot.html`** on your phone (or use **Mint** in the terminal bottom nav → **Open METABOT**).
2. Prefer your wallet’s **in-app browser** (MetaMask / Rainbow / Trust) so `Connect Wallet` works natively.
3. Or tap **Connect Wallet** in Safari/Chrome to get deep-links that open the page inside those apps.
4. Add to Home Screen (PWA) via Share → Add to Home Screen for one-tap access on the go.

No PC prompt required for day-to-day mints.

## Dev

```bash
npm run dev
# → http://localhost:8080/metabot.html
# → http://localhost:8080/index.html#bot
```

```bash
npm run lint
```
